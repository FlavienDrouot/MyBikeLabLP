## Archival conventions

- Archived work keeps its ID and historical folder or file name.
- The complete work item is preserved unless a separate migration is approved.
- The active index and this archive index are updated together.
- Legacy artifacts may use `evolution.md`, `iterative-evolution.md`, `task.md`, or older standalone Markdown files.
- Historical references are not rewritten solely to repair old paths.
- `Archived` means that the item is no longer active in the current navigation. The original completion status is retained when known in the work item.
