# Wheel Detail UI Kit

Single-wheel **spec sheet** — treats one wheelset as if it were a piece of measurement equipment. Designed for the "I clicked a row, now show me everything" moment.

## What's here

- **Page header** with breadcrumb back to comparator
- **Title block** — brand · model · key stat trio (weight, depth, min price)
- **Schematic side** — technical wheel illustration with dimension annotations
- **Spec sheet** — full key/value list, grouped (General / Rim / Hub / Spokes)
- **Retailer ladder** — list of known retailers with prices, ordered cheapest first, with affiliate-link CTAs
- **Comparable wheels** strip — three closest matches at the bottom
- **Disclaimer** — "indicative prices" annotation

## Files

- `index.html` — entry
- `App.jsx` — composes the layout
- `detail.css` — surface-specific layout
