# Consolidated direction - wave 4

## Position in PR #42

Wave 4 is a continuation of the refined-console work already contained in PR
#42. Wave 3 established the structural system. Wave 4 changes the visual
finish and restores comparator details that were already present in the live
product.

Production code remains untouched.

## What is locked

- Landing and comparator are one continuous public page.
- Comparator keeps a left filter rail and a right results surface.
- Overview-first density remains the priority.
- Wheel detail does not need another exploration pass.
- Existing logo mark and wordmark treatment remain.
- No new product features are introduced.

## Visual direction

### Light - primary

The preferred direction takes the cooler Wave 3 console as its base and adds a
small amount of materiality:

- slightly brighter page field and white elevated panels;
- stronger but still restrained blue for active states;
- soft surface shadows and hairlines;
- large, low-opacity wheel/rim geometry and fine technical line textures used
  only as decoration;
- no decorative text, fake measurements, fake status labels or ornamental
  metadata.

### Cream - optional

Cream is the same system, not a separate design. It replaces the cool field
with warm mineral/paper neutrals and moves the accent toward muted brass. The
warmth is deliberately controlled so it does not return to the earlier
editorial/workshop role-play.

### Dark - optional

Dark stays in the moderate charcoal register validated in Wave 3. It inherits
exactly the same decorative geometry and component hierarchy, with relief
coming primarily from surface steps and hairlines.

## Comparator corrections

The Wave 3 standalone comparator grouped too many unrelated controls under a
single open "General" section. Wave 4 moves closer to the current product:

- Brand is a dedicated group;
- Brand opens with a search field and a fixed-height inner list;
- the list scrolls independently when more brands are present;
- Price, Weight, Brake type and Category remain separate groups;
- each filter family has a visible on/off switch;
- active filter chips remain visible above the result table;
- table density and the eight-column desktop overview remain unchanged in
  spirit.

The prototype makes toggles and collapsible groups interactive only so the
visual states can be evaluated. It does not implement catalog filtering.

## Decoration boundary

Accepted decoration must be unambiguously visual. It may create depth,
movement or cycling-specific atmosphere, but it must not look like hidden
information.

Accepted examples in this wave:

- ghosted wheel circles;
- spoke/rim line geometry;
- very light grid or contour textures;
- diffuse accent glow tied to a theme;
- subtle material variation inside large empty areas.

Still rejected:

- meaningless serial numbers;
- pseudo-instrument labels;
- decorative measurement values;
- fake system states;
- editorial/workshop props that suggest content where none exists.

## Review criterion

Wave 4 succeeds if it feels more recognisably MyBikeLab than Wave 3 while a
returning user can still immediately recognise the same product, the same
content hierarchy and the same comparator workflow.
