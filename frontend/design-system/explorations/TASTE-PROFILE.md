# MyBikeLab taste profile

Living record of the owner's visual taste signals, distilled from mockup
arbitration and reference reviews. Feeds every future wave brief. Update after
each arbitration round; date each addition.

## Wave 1 (2026-08-22, five landing candidates)

### Confirmed rejections
- **Visual overload.** Dense, busy compositions rejected four times out of
  four. Airiness is a requirement, not a preference.
- **Non-informative labels.** Systematic "№ XX" counters, tickers,
  pseudo-technical stamps (`SYS //`, `REV 2026.Q2`, `G-01 / COUNT`,
  `Doc № MBL-LP-E01`), decorative margin notes: all called out as useless or
  ornamental. Rule candidate: if an element carries no information, it must go.
- **Editorial role-play.** Newspaper masthead/issue numbers/reply coupons,
  workshop doc cartouches and stamped plates: rejected as costume ("on se
  demande s'il y a une info dedans ou non"). The page must be a real product
  page, not a staged artifact.
- **Oversized display type in content zones.** Hero-scale titles compete with
  useful content ("titre trop gros"). Large type accepted where it encroaches
  on nothing (giant footer wordmark explicitly liked).
- **Near-black darkness.** Even accepting dark mode in principle, the
  night-instrument near-black was judged too dark.
- **LLM-classic warm palettes.** Cream + bronze/rust/paper + orange flagged as
  a scheme "très classique des LLM". Implication: the current paper+brass
  identity itself sits in this family and may need to move.
- **Full flush-left composition** felt odd at wide desktop sizes; classical
  balanced alignment expected.

### Confirmed attractions
- **Sober, airy, refined surfaces.** Swiss-data ranked best of wave;
  print-magazine's relative restraint positively noted.
- **Aligned figure presentations.** Stats ledgers / registers read well.
- **Structural ideas over styling:** roadmap as a timeline strip (swiss-data)
  and sequenced phase plates (workshop-manual) both found interesting; benefits
  presentation interesting once filler labels removed.
- **Informative illustration concept.** An exploded component view suggesting
  "we will enter the detail of components" appealed, but only if it reads as
  informative instantly; purely aesthetic illustrations waste the reader's time.

### Open questions
- **Distinctiveness paradox:** current design judged not distinctive enough,
  yet every radical direction failed. Differentiation likely has to come from
  structure, typographic detail, color, and data presentation rather than from
  a stylistic costume.
- **Dark mode appetite:** unclear; moderate values only, if any.
- **Color direction:** away from cream+bronze; target family unknown.

### Wave-2 brief implications
1. Zero non-informative elements; every label must earn its place.
2. Restrained display scale; hierarchy through weight/spacing, not size shocks.
3. If dark surfaces appear, keep them moderate.
4. Palette must escape the cream+bronze/orange cliché.
5. Balanced, centered-friendly composition for wide screens.
6. Illustrations allowed but must inform at first glance.
7. Keep validated structural ideas: roadmap timeline, sober stat ledgers,
   non-encroaching large brand moments.

### Next calibration step
Reference pass on existing real sites before producing new mockups
(owner proposal, adopted): browse curated live references, react per site,
distill attributes, then brief wave 2.

## Wave 2 arbitration (2026-08-22, issues #39)

### Outcome
- **Light premium console = retained primary direction.** "Globalement c'est
  très bon."
- **Dark mode kept as secondary theme** (some users prefer it), with a new
  named reference: the recent VS Code dark update ("Dark Modern") - deep
  neutral near-uniform surfaces, calm, low chroma, hairline separation. The
  wave-2 dark-moderate structure is accepted; the target darkness/mood is the
  VS Code register.
- **Current logo liked and reusable**: `design-system/assets/logo-mark.svg`
  (stroke-based M in a registration frame) adapts to any palette.
- **No dot after the MyBikeLab wordmark** (both candidates added one).
- **Navbar opacity slightly reduced** requested.
- **Gray background monotony must be broken** on the light theme - first
  weakness flagged on the winning direction.

### Implications for next waves
1. Extend the retained direction to comparator + wheel detail surfaces.
2. Provide light + VS Code-inspired dark theming of the same system.
3. Wordmark without trailing dot; reuse the existing logo mark.
4. Introduce legitimate variation into light backgrounds (surface bands,
   keylines, informative schematic moments) without costume.

### New signals
- **Flat utility is rejected as firmly as decoration.** Pure-minimal
  comparison tools read as amateur ("atelier HTML pour débutants"). Surfaces
  need perceptible structure: separated zones, component relief.
- **White-on-white monotony** flagged twice (DXOMark, Bike Insights):
  light background alone does not create hierarchy.
- **Scroll-cost awareness.** Premium marketing pages judged excellent on mood
  but their spec presentations fail the overview test: too airy, information
  buried below the fold. Overview beats theatrical pacing.
- **Screen width should be used.** Narrow single-column flows feel wasted
  ("un peu trop linéaire").
- **Photo dependence identified by the owner himself:** the premium-cycling
  mood rests on large photography and must be transposed to a data product
  through typography, spacing, and surface treatment instead.
- Accent-color evidence so far: mass red-on-white rejected; cream+bronze
  family rejected; swiss-data's single punctual red was never criticized.
  Dosage matters more than hue.

### Taste equation v2
1. Mood: premium restraint, zero costume (PNS register transposed to data).
2. Surfaces: clearly separated zones with moderate relief; no white-on-white,
   no flat utility sheets.
3. Density: moderate with overview first; key info reachable without long
   scrolls; breathing room preserved around dense blocks.
4. Layout: uses wide screens; avoids both single-column linearity and
   cramming.
5. Accents: punctual only; outside cream+bronze/orange and mass-red families.
6. Visuals: informative at first glance or absent.

### Wave-2 direction candidates distilled
1. **Light premium structured console**: cool neutral base, elevated panels
   with hairline/subtle-shadow separation, overview-first spec tables,
   restrained display scale, one cool accent.
2. **Moderate dark variant** of the same equation (dark mode done moderate).
Wave 2 should test these two against each other on the landing, carrying over
validated structural ideas: roadmap timeline, stat ledgers, non-encroaching
large brand moments.
